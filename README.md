# CAT201 ASSIGNMENT 2

### How to run the website:
1. Install Node.JS here: https://nodejs.org/
2. Open VS Code and open the terminal and type this command line :
    ```
    mkdir CAT201-Assignment-2
    cd CAT201-Assignment-2
    npx create-react-app client
    mkdir server
    ```
    to create new project folder
3.  Enter this command line after wards to initialized Node.js backend:
     ```
    cd server
    npm init -y
    npm install express cors
     ```
4. Download all the files in both folder in the repository and move the files in components folder in the components folder in the src folder created by the command in 2 & 3 and change the public folder with the one in the repository (you need to create the components folder yourself)
5. Change the App.js and App,css created by the commands with the one in the repository
6. Right click on the client folder that have been created in by the line command in 2 & 3 and click on the open in intergrated terminal to open terminal accessed to the client folder and run the following command : `npm start` run the website
7. Congrats you have successfully run the website
